# MC CC Scripts Code Hub

Static GitHub Pages hub for CC:Tweaked computers.

Install in ComputerCraft:

```lua
wget https://raw.githubusercontent.com/HerenYU2007/mc-cc-scripts/main/ccget.lua ccget
ccget setup HerenYU2007 mc-cc-scripts main scripts
ccget list
```

Open the web uploader after GitHub Pages is enabled:

https://HerenYU2007.github.io/mc-cc-scripts/
